# Firestore Tournament Matches Schema

## Collection: `matches`

Each document represents a single match in the bracket.

### Fields:
- `matchId` (string): Unique match identifier, e.g. `1_1` (phase 1, match 1)
- `phase` (number): Tournament phase (1-5)
- `teamA_id` (string|null): Firestore ID of team A (or null for bye)
- `teamB_id` (string|null): Firestore ID of team B (or null for bye)
- `teamA_name` (string|null): Display name of team A
- `teamB_name` (string|null): Display name of team B
- `scoreA` (number|null): Score for team A
- `scoreB` (number|null): Score for team B
- `winnerId` (string|null): Firestore ID of the winner (set after match is played)
- `nextMatchId` (string|null): ID of the next match in the bracket (or null for final)

## Example Document
```json
{
  "matchId": "2_3",
  "phase": 2,
  "teamA_id": "teamIdA",
  "teamB_id": "teamIdB",
  "teamA_name": "Wilki",
  "teamB_name": "Żbiki",
  "scoreA": 4,
  "scoreB": 2,
  "winnerId": "teamIdA",
  "nextMatchId": "3_2"
}
```

## Initialization
- To initialize a tournament, clear the `matches` collection and insert all matches generated by `generateTournament(teams)`.
- As matches are played, update `scoreA`, `scoreB`, and `winnerId`.
- When a match is completed, update the corresponding `teamA_id` or `teamB_id` in the `nextMatchId` match document with the `winnerId`.
